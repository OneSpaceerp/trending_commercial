# Trending Commercial (ERPNext v16 Custom App)

An upgrade-safe ERPNext v16 custom application for **Trending Experiential** that standardizes and digitizes the commercial lifecycle from Brief intake to Project creation, operational Costing, controlled Quotations with Agency Fees & VAT, multi-tier approvals with delegation, and an interactive executive dashboard.

## Features
- **Commercial Brief**: Replicates Trending CRM's intake flow with dynamic questionnaires across 14 sub-domains. Automatically instantiates an ERPNext Project (`{Customer} - {Title}`).
- **Commercial Costing Sheet**: Enables Account Managers and Operations to draft freeform itemized costs without inventory item search, preserving true Cost of Goods Sold (COGS).
- **Quotation Engine**: Implements Trending CRM's exact mathematical model (15% Agency/Management Fee, 14% VAT on Items + Fee, and payment milestones).
- **Approval Engine & PDF Security**: 4-tier approval limits, temporary delegation, and server-side PDF lock/watermark for unapproved quotations.
- **Sales Order & Invoice Continuity**: Maps commercial lines, milestones, and project links cleanly to downstream accounting.
- **Trending Hub Interactive Dashboard**: Full desk page featuring greeting, KPIs, commercial pipeline, 6-department project status tracker, and activity feed.
